# Portfolio Development Guidelines

## Project Rules
- Improve the existing portfolio; never rebuild it unnecessarily.
- Preserve branding, content, routes, and functionality.
- Follow the existing technology stack.
- Reuse existing components.

## Design Standards
- Maintain consistent typography.
- Prioritize text readability.
- Use consistent card backgrounds and borders.
- Maintain sufficient color contrast.
- Follow a consistent spacing system.

## Responsive Standards
- Use mobile-first responsive design.
- Prevent horizontal overflow.
- Test mobile, tablet, and desktop layouts.
- Ensure navigation works on touch devices.

## Code Quality
- Write clean, maintainable code.
- Avoid unnecessary dependencies.
- Avoid duplicate CSS.
- Preserve existing functionality.
- Check for errors after modifications.

## AI Agent Instructions
- Inspect before editing.
- Plan before implementing.
- Work in small batches.
- Explain important changes.
- Review modified files.
- Run available tests and builds.
- Never claim unverified testing results.
